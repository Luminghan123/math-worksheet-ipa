# 小学数学出题 · 口算题卡 APP

一个**个人自用**的 iOS APP 方案与可运行原型：家长配置年级、题型、难度，一键生成 **A4 可打印试卷**，每页固定 **125 道题、5 列 × 25 行整齐网格**，导出 PDF / PNG 后打印给孩子做。

---

## 一、已确认的需求清单

| 项 | 内容 |
|---|---|
| 目标用户 | 你自己（家长），个人自用；实际做题人为自家小学生孩子 |
| 使用场景 | 想给孩子补数学练习时，配好条件 → 生成 A4 试卷 → 导出 PDF/图片 → 打印 |
| 核心用途 | 生成小学生数学题 |
| 使用方式 | 排版成 A4 可打印试卷，导出 PDF/图片 |
| 出题设置 | 年级与知识点范围、题型组合、题量与难度 |
| 排版规格 | A4 竖版、**每页 125 题、5 列、排列整齐**；答案横线贴文字基线，不悬在格子垂直正中 |
| 题型范围 | 只做短算式：口算 / 竖式 / 填空（长题目放不进密排网格） |
| 页面结构 | 标准版：首页试卷列表 + 新建配置 → 预览 → 导出 |
| 目标平台 | iOS（最终要 ipa） |
| 本版不做 | 参考答案页、手机直接做题判分、常用配置模板、独立设置页 |

## 二、功能架构

| 层级 | 功能 | 所在页面 |
|---|---|---|
| 核心 | 年级/学期选择，按知识点自动收敛运算符（不超纲） | 新建试卷 |
| 核心 | 题型组合多选 + 占比微调，合计 125 题 | 新建试卷 |
| 核心 | 页数即题量（每页固定 125 题）、数值范围难度、每题分值 | 新建试卷 |
| 核心 | 按配置随机生成短算式，5 列 × 25 行整齐网格 | 试卷预览 |
| 核心 | A4 精确分页（页眉：姓名/日期/用时/得分/满分） | 试卷预览 |
| 核心 | 直接生成并下载 PDF（A4 精确分页）/ PNG 文件，弹层内保留可见下载入口 | 导出弹层 |
| 辅助 | 历史试卷列表，可复开、重新导出、删除 | 首页 |
| 辅助 | 「换一批」按当前配置重出题目 | 试卷预览 |
| 后续迭代 | 参考答案页、手机做题判分、配置模板、设置页 | — |

**关于 0 的运算**：加减法操作数允许 0（如 `0 + 5`、`8 − 0`、`6 − 6 = 0`），且每页固定插入 10 道含 0 的运算，覆盖 `0 × 8`、`8 × 0`、`0 ÷ 6`、结果为 0 等情况，保证试卷里一定出现 0 的运算。含 0 的乘除题同样按年级收敛（一二年级不会出现 `0 ÷ 6`）。

**答案横线**：只有等号后留空的常规算式（`27 + 31 = ____`）才带答案横线；含 `□` 的填空题（如 `8 + □ = 15`、`□ × 5 = 25`）答案直接写在方框内，末尾不再添加横线。横线贴文字基线，不悬在格子垂直正中。

## 三、页面地图

```
首页 · 我的试卷 (P1)
 ├─ 新建试卷 · 配置 (P2)
 │   └─ 试卷预览 (P3) ── 导出弹层 (E1)
 └─ 试卷预览 (P3，从历史卡片进入，复用同一页)
```

## 四、逐页排版说明

**P1 首页**｜目标：找到旧试卷或发起新建。模块：大标题「我的试卷」+ 右上「+」→ 概览条 → 试卷卡片列表（名称/年级/页数·题数/时间）→ 空状态引导。层级：大标题 > 试卷名 > 灰色副信息。交互：点卡片进 P3，卡片内删除，右上「+」进 P2。

**P2 配置页**｜目标：一次配好条件。自上而下：① 年级与学期（下方自动显示知识点范围）② 题型组合（多选 chips + 每项占比 ±，实时显示题数）③ 页数与题量（1–5 页，实时显示总题数）④ 数值范围难度 ⑤ 每题分值 → 底部固定「生成试卷」主按钮。层级：分组标题 > 控件 > 辅助说明，主按钮最突出。交互：换年级自动收敛运算；占比自动归一到 100%；生成后进 P3。

**P3 试卷预览**｜目标：确认 A4 成品再导出。模块：顶部导航（返回 / 页码 / 导出）→ 翻页与「换一批」工具条 → A4 纸张：标题 → 姓名·日期·用时·得分栏 → 满分说明 → **5 列 × 25 行 = 125 题网格（细线分格、等宽列、行距均匀）** → 页脚页码。纸张为唯一视觉主体，题目字小但严格对齐。

**E1 导出弹层**｜顶部「下载结果」区（显示文件名与大小 + **点此下载** / **新窗口打开** 两个可见入口）→ **下载 PDF（主按钮）** / 当前页 PNG / 全部页 PNG → 备用「浏览器打印 / 另存为 PDF」→ 取消。生成后弹层不关闭，保证下载入口一直可见；试卷在生成时已自动存入历史。

## 六、原型怎么用

直接用浏览器打开 `index.html` 即可（桌面端会显示成一台手机，手机端自动全屏）。

1. 首页点右上 **+**
2. 选年级（自动收敛可用运算）、勾题型并调占比、设页数/数值范围/每题分值
3. 点 **生成试卷** → 进入 A4 预览，确认 5 列 × 25 行网格
4. 点右上 **导出** → **下载 PDF（推荐）**，弹层顶部会出现「已生成 xxx.pdf」和蓝色 **点此下载** 按钮；也可选当前页 / 全部页 PNG，或底部备用的「浏览器打印 / 另存为 PDF」

> **不用打印框了**：PDF 由页面直接生成（A4 精确分页，每页一张约 192 DPI 图片，中文不会乱码），点按钮就下载文件。若浏览器拦截了自动下载，点弹层里的 **点此下载**；手机上可长按链接选「存储到文件」，或点 **新窗口打开** 后用分享菜单另存。图片型 PDF 文字不可复制，但打印清晰。

历史试卷保存在浏览器本机（localStorage），可复开、重新导出、删除。原型已带 `apple-mobile-web-app-*` 元信息，手机上「添加到主屏幕」后可全屏当 APP 用。

## 七、关于「生成 ipa」

> **有巨魔（TrollStore）？** 见 [TROLLSTORE-IPA.md](./TROLLSTORE-IPA.md)：把本目录推到 GitHub，Actions 用 macOS 云端构建机产出**未签名 ipa** 并发布到 Releases，手机直接下载安装，**不需要 Apple 开发者账号**。

**正规签名的 ipa 只能在 macOS 上用 Xcode 配合 Apple 签名证书编译导出。** 本沙箱是 Linux 环境，没有 Xcode / CocoaPods / Apple 开发者证书，因此无法在这里直接产出可安装的 `.ipa` 文件。

本目录交付的是**可以直接打包成 ipa 的 iOS 壳工程源码 + 完整步骤**：`ios-shell/` 是一个 Capacitor 工程，`www/index.html` 就是上面的原型。把它拷到 Mac 上按下面做，即可得到 ipa。

### 路线 A：Capacitor 打包成 ipa（推荐，能拿到真正的 ipa）

**前提**：macOS、Xcode 15+、Node 18+、CocoaPods、Apple Developer 账号（免费账号可做 development 签名装到自己设备；Ad Hoc / App Store 需付费账号）。

```bash
cd ios-shell
npm install                    # 安装 @capacitor/core / ios / cli
npx cap add ios                # 生成 ios/App 原生 Xcode 工程
npx cap sync ios               # 把 www/ 同步进原生工程
npx cap open ios               # 打开 Xcode
```

在 Xcode 里：

1. 选中 `App` target → Signing & Capabilities → 勾选 **Automatically manage signing**，Team 选你的开发者账号
2. 把 Bundle Identifier 改成你自己的（与 `capacitor.config.json` 的 `appId` 一致，如 `com.yourname.mathworksheet`）
3. 顶部设备选 **Any iOS Device (arm64)**
4. `Product > Archive` → Organizer → `Distribute App` → 选 **Development / Ad Hoc / App Store** → 一路下一步导出，即可得到 `.ipa`

也可以用命令行一步导出（脚本已附在 `ios-shell/build-ipa.sh`）：

```bash
# 先在 Xcode 里完成一次签名配置，并修改 ExportOptions.plist 里的 teamID
cd ios-shell
chmod +x build-ipa.sh
./build-ipa.sh
# 输出：ios-shell/build/ipa/App.ipa
```

`build-ipa.sh` 内部执行两条 `xcodebuild`：`clean archive` 生成 `.xcarchive`，再 `exportArchive` 按 `ExportOptions.plist` 导出 ipa。若报签名错误，先用 `npx cap open ios` 在 Xcode 里把 Team 配好。

### 路线 B：不打包，立刻在手机上用（无需开发者账号）

把 `index.html` 部署成静态网页（任意静态托管 / 内网即可），手机浏览器打开后「添加到主屏幕」，图标和全屏体验接近原生 APP。优点是零成本、马上可用；缺点是拿不到 `.ipa` 文件、不能上架 App Store。

### 两条路线的取舍

| | 路线 A（Capacitor → ipa） | 路线 B（PWA 网页） |
|---|---|---|
| 产出 ipa | ✅ | ❌ |
| 需要 Mac + Xcode | ✅ | ❌ |
| 需要开发者账号 | 真机/上架需要 | ❌ |
| 上架 App Store | ✅ | ❌ |
| 立即可用 | 需打包 | ✅ |

> 建议：先用 `index.html` 验收功能和版式，确认没问题后再走路线 A 打包 ipa，避免反复改原生工程。
